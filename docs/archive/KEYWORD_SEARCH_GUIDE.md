# Keyword Search Guide

## How to Find Images on Your System

The AI Assistant can now search your entire system for images by keyword!

---

## Usage Examples

### Find by Keyword
```
"find guitar image"
"find vacation photo"
"find logo picture"
"find screenshot"
```

### Search Locations
The assistant searches in:
1. ~/Pictures
2. ~/Downloads
3. ~/Desktop
4. ~/Documents

### What It Looks For
- Filenames containing your keyword
- All image formats: jpg, jpeg, png, gif, bmp, webp, svg
